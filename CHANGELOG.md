# Changelog

## 1.0.0

- Initial public version: Sal's Graphical Tweaks.
- Adjustable shadow distance, sun resolution and sharp shadow range.
- 1–10× decal visibility with slider, numeric input and reset.
- Glass sunlight occlusion and seamless rendering across eleven borderless
  glass definitions, including supported mirrored and partial tetra/hepta joins.
- Empty-pass and ambient occlusion lifecycle optimisations.
- Optional experimental decal CPU optimisation.
- Shortened setting descriptions and added player installation instructions.
